How to install

  1. Connect the display to this computer with a USB-C data cable.
  2. Pick the board and machine above, press Connect and install, and choose the port (often "USB JTAG/serial debug unit").
  3. To keep your settings and Wi-Fi when updating, leave Erase device off.
  4. If it doesn't connect, hold the board's BOOT button, tap RESET, release BOOT, and try again. Press RESET when it's done.

Updates over Wi-Fi

Once the display has Wi-Fi set up (Settings > Wi-Fi), it checks for a new version each time it syncs its clock, weekly or when you press SYNC, and installs it by itself. If a new version fails to start, it goes back to the previous one.
