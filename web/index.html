Rowing Display

A colour touch console for home rowing machines. Plug the display into this computer with USB and flash it from this page. You don't need to install anything.

Display
Rowing machine
Your browser can't flash over USB. Use Chrome or Edge on a desktop computer. Flashing needs a secure page (https). The machine only sets the first-boot preset. You can change it later under Settings.

How to flash

  1. Connect the display to this computer with a USB-C data cable.
  2. Pick your display and machine above, then click Install firmware and choose the serial port.
  3. When it asks whether to erase the device: don't erase keeps your settings. Erase resets them to the preset.
  4. Flashing takes about a minute. The display restarts by itself when it's done.

If it doesn't connect

  • No port in the list: try another cable. Many USB-C cables only carry power.
  • The port shows up but flashing doesn't start: unplug the cable, hold the BOOT button while you plug it back in, let go, and try again. Unplug and replug once more after flashing.
  • Close any other program that has the port open, such as a serial monitor or PlatformIO.

After installing

  • Scene backgrounds and session files use the SD card. See Backgrounds in the README.
  • Sensor wiring for each machine is in Hardware.md.
  • To flash from the command line instead, download the image for your board from the latest release and write it at offset 0: esptool.py write_flash 0x0 rowing-display-…bin
